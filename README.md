# SkillSharing

### Contexte

Application réalisée lors d'une évaluation web Django dans le cadre d'un parcours d'apprentissage CDA

### Description

Il s'agit d'une application ayant pour but de mettre en relation des utilisateurs
compétents dans un domaine préçis avec d'autre utilisateurs ayant besoin d'aide.

## Installation

### 1. Cloner le dépôt

```bash
git clone https://github.com/ArnaudD-fms/Eval_web_python.git
cd Eval_web_python
```

### 2. Créer un environnement virtuel

```bash
python -m venv .venv
```

Sous Windows :

```bash
.venv\Scripts\activate
```

Sous Linux ou macOS :

```bash
source .venv/bin/activate
```

### 3. Installer les dépendances

```bash
pip install -r requirements.txt
```
